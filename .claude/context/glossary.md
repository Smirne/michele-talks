# Glossary

One term per concept. Use these words in specs, plans, code and UI text.

| Term | Meaning | Not to be confused with |
|---|---|---|
| **Talk** | A presentation in the catalogue that the speaker can give. Has a title, abstract, duration, level, format and the language(s) it can be given in. | An Appearance (one occasion it was given). |
| **Appearance** | One occasion the speaker spoke at an event: event name, date, location (or online), language. May link to a Talk, but doesn't have to (e.g. a panel). Upcoming if dated after today. | A Talk; an "event" is only the Appearance's venue name, not a separate entity. |
| **Resource** | Slides or a video attached to an Appearance, with its own type and language. | — |

Source: specs/001-site-foundation (approved 2026-11-19).
